# Braço Robótico com Arduino

Este repositório contém o código que desenvolvi durante as aulas de robótica no ensino médio para controlar um braço robótico utilizando Arduino.

Na época, o código disponibilizado no material da disciplina não funcionou no braço. Por isso, decidi estudar o projeto e criar minha própria solução. Depois de vários testes e ajustes, consegui movimentar as articulações e controlar a garra do robô.

Este é o código original que criei naquele período e estou publicando hoje no GitHub como registro do projeto e da minha evolução na programação. Atualmente, reconheço que ele possui erros e pontos que poderiam ser melhorados, mas foi por meio dele que consegui fazer o braço robótico funcionar.
